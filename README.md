# Kevin Kiprotich — Personal Website

The source for [kevinkipro.com](https://kevinkipro.com), Kevin Kiprotich's
personal website. The current version is an intentionally minimal starting
point containing only Kevin's name.

## Run locally

This is a static site with no build step. Open `index.html` in a browser, or serve the folder with any local web server.

## Publishing

The site is published through GitHub Pages from the root of the `main` branch.
